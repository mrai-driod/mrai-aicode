## Comments
- Write no comments by default. Add one only when *why* the code is written that way is not obvious: a hidden constraint, a subtle invariant, a workaround for a specific bug, or surprising behaviour.
- Never explain *what* the code does in a comment, and never reference the current task, change, or caller in one.
- Leave no commented-out old code behind.
