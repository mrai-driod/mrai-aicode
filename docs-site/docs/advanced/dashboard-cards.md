# DIY Dashboard and Adaptive Cards design specification guide

This document defines the **Adaptive Cards declarative micro-template specification** supported by AiCode's "DIY Dashboard" above the chat input box.

Following this specification, AI assistants and developers can write dashboard scripts (Python / Node / Shell) that output structured card JSON, fully customizing the dashboard's layout, colors, progress bars, metric cards, and detail information in both the collapsed (Compact) and expanded (Expanded) states.

---

## 1. Script location and management

### 1.1 Default location
- **Unified script directory**: `~/.aicode/scripts/`. In local mode this is `/root/.aicode/scripts/` inside the container, mapped to the host app's data directory and preserved across container upgrades and reinstalls; in remote mode it's `~/.aicode/scripts/` under the server user's home (the remote side is authoritative — reads and writes all happen remotely).

### 1.2 Writing scripts and language support
A script only needs to print its standard JSON result to **standard output (stdout)**:
- **Python scripts** (`.py` suffix): executed automatically via `python3 <script_path>`;
- **NodeJS scripts** (`.js` suffix): executed automatically via `node <script_path>`;
- **Shell scripts** (`.sh` / `.bash` suffix): executed automatically via `bash <script_path>`;
- **Binary / executable scripts**: if they have execute permission (`chmod +x`), executed directly.

### 1.3 Path resolution rules
In the "Dashboard script" field of the provider settings, the following path forms are supported:
1. **Plain file name** (recommended, e.g. `demo_balance.py`): looked up automatically in the `~/.aicode/scripts/` directory;
2. **Relative path** (e.g. `scripts/my_panel.py` or `.aicode/scripts/my_panel.py`): expanded automatically from `~/.aicode/`;
3. **Tilde path** (e.g. `~/.aicode/scripts/my_panel.py` or `~/my_script.py`): expanded automatically to the home of the current execution environment (the local container is `/root`; remote is the server user's home);
4. **Absolute path inside the container** (e.g. `/root/workspace/scripts/quota.py`).

## 2. Script runtime environment and injected environment variables

When running a dashboard script, AiCode automatically injects the following environment variables, which scripts can consume freely to build dynamic dashboards:

### Token variables

> **A note on "input tokens"**: `LAST_INPUT_TOKENS` and `TOTAL_INPUT_TOKENS` are both the **total input tokens** returned by the API (i.e. `input_tokens` / `prompt_tokens` / `promptTokenCount`), **already including the cache-hit portion**. `LAST_CACHED_TOKENS` is the portion of that which hit the server-side cache (a subset). So net new input = `LAST_INPUT_TOKENS` - `LAST_CACHED_TOKENS`.
>
> **A note on the model variables**: the `AICODE_MODEL_*` series in the table below all follow the **current channel** — the custom window, unit price, and capability toggles you filled in for that model under Provider → Model take effect directly; only values you didn't fill in fall back to the auto-detected results.

#### Custom script parameters (Dashboard / DIY scripts)

Under "Edit provider → Dashboard (DIY)" you can configure any number of custom script parameters (Key-Value).
When the dashboard script runs, each parameter is injected into the script's environment variables in the form `AICODE_KEY_<KEY>`:

- KEY is normalized to **uppercase**, keeping only letters, digits, and underscores, e.g. ACCOUNT_ID → AICODE_KEY_ACCOUNT_ID;
- Keys with the same name are case-insensitive; on conflict, the one added later wins;
- Parameter values can reference placeholders of the current provider's configuration, so sensitive information (such as the API Key) doesn't have to be entered repeatedly.

::: v-pre
| Placeholder | Description |
| :--- | :--- |
| {{PROVIDER_API_KEY}} | The currently active API Key |
| {{PROVIDER_ID}} | Provider record ID |
| {{PROVIDER_NAME}} | Provider name |
| {{PROVIDER_TYPE}} | Upstream format (OPENAI / ANTHROPIC / GEMINI) |
| {{BASE_URL}} | Provider Base URL |
| {{DEFAULT_MODEL}} | Default model |
| {{SELECTED_MODEL}} | Currently selected model |
| {{MODEL}} | The model actually in effect (selected first, then default) |
:::

Example: configure a parameter with KEY=ACCOUNT_ID and VALUE=<span v-pre>{{PROVIDER_API_KEY}}</span>, and the script will have
AICODE_KEY_ACCOUNT_ID=<current API Key> injected.

## 3. Design philosophy and architectural principles

- **Declarative UI**: scripts only output a JSON description tree to standard output; they don't intrude into Android's native drawing code.
- **Pure native Compose rendering**: the description is parsed and drawn by the native Jetpack Compose component tree, keeping expand/collapse animations smooth.
- **Automatic theme adaptation**: all semantic colors (such as `Good`, `Warning`, `Attention`, `Accent`, `Subtle`) automatically adapt intelligently to the app's light/dark theme — no need to hardcode multiple theme sets.
- **Dual-State Architecture**:
  - **Compact View**: a compact single-row strip above the input box (about 28dp–34dp tall), for permanently displaying core quota or status.
  - **Expanded View**: the rich card panel shown after tapping to expand (adaptive height), supporting multi-column grids, itemized bills, large metric blocks, and action buttons.
- **Event-driven real-time refresh mechanism**:
  - **Instant refresh on every LLM response**: in the agent workflow, every time a single API request completes (with the latest input/output tokens available), the app automatically re-runs the script with the newest context and refreshes the dashboard;
  - **Page entry and manual refresh**: first entering a session, changing the script in settings, or clicking the dashboard refresh button all trigger an immediate refresh.

## 4. Root structure definition (Root Card Schema)

The standard output of a dashboard script should be the following root structure:

```json
{
  "type": "AdaptiveCard",
  "version": "1.5",
  "compact": {
    "type": "Row",
    "items": [ ... ]
  },
  "body": [ ... ]
}
```

### Root field reference

| Field | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `type` | String | Yes | - | Always `"AdaptiveCard"` |
| `version` | String | No | `"1.5"` | Specification version number; `"1.5"` recommended |
| `compact` | Container | No | `null` | Content definition for the **collapsed state** (a single-row compact container). If omitted, the system automatically extracts the first 2–3 main metrics from `body` and generates one intelligently |
| `body` | Array | Yes | `[]` | The card body container and component tree list for the **expanded state**. Interactive elements such as buttons must also be placed in `body` (see `ActionButton` below) |

## 5. Complete element and container reference (Elements Reference)

### 5.1 Containers and layout elements

> **Common property `visible`**: every element accepts `"visible": false` to hide it; the element is skipped entirely during parsing and not rendered. Useful for dynamically controlling visibility based on environment variables.

#### `ColumnSet` (multi-column grid container)
Arranges child elements side by side in multiple horizontal columns; the core container for building multi-period metrics and side-by-side comparison cards.

- **Properties**:
  | Property | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Always `"ColumnSet"` | - |
  | `columns` | Array<Column\> | `[]` | List of column objects it contains |
  | `spacing` | String / Number | `"Medium"` | Column spacing enum or number (e.g. `8`, `"10dp"`) |
  | `gap` | Number / String | `null` | Exact spacing between columns (e.g. `8`, `"12dp"`; takes precedence over `spacing`) |
  | `padding` | Number / Array / Object | `null` | Container inner padding (e.g. `8`, `[4, 8]`, or `{ "top": 4, "right": 8 }`) |
  | `margin` | Number / Array / Object | `null` | Container outer margin |
  | `minHeight` | Number / String | `null` | Minimum height constraint (e.g. `48`, `"48dp"`) |
  | `horizontalAlignment` | String | `"Left"` | Horizontal alignment: `"Left"`, `"Center"`, `"Right"` |

#### `Column` (a single column)
A child element of `ColumnSet`; content elements are stacked vertically inside it.

- **Properties**:
  | Property | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Always `"Column"` | - |
  | `width` | String / Number | `"stretch"` | Width mode:<br>• `"auto"`: minimum width fitted to content<br>• `"stretch"`: equal share of the remaining available space<br>• numbers like `"1"`, `"2"`, `"3"`: flexible weight ratio<br>• `"50px"`, `"50dp"`: fixed width |
  | `separator` | Boolean | `false` | When `true`, shows a thin vertical divider line from the previous column |
  | `spacing` | String | `"None"` | Vertical spacing enum between child elements in the column: `"None"`, `"Small"`, `"Medium"`, `"Large"` |
  | `gap` | Number / String | `null` | Exact vertical spacing between child elements in the column (e.g. `4`, `"6dp"`; takes precedence over `spacing`) |
  | `padding` | Number / Array / Object | `null` | Inner padding of the column (e.g. `4`, `[2, 4]`) |
  | `minHeight` / `maxHeight` | Number / String | `null` | Minimum/maximum height constraints |
  | `minWidth` / `maxWidth` | Number / String | `null` | Minimum/maximum width constraints |
  | `verticalContentAlignment` | String | `"Top"` | Vertical alignment inside the column: `"Top"`, `"Center"`, `"Bottom"` |
  | `items` | Array<Element\> | `[]` | List of elements arranged vertically in the column |

#### `Container` (generic block container)
Used to package several elements into a standalone card, highlight block, or grouped background.

- **Properties**:
  | Property | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Always `"Container"` | - |
  | `style` | String | `"Default"` | Container style: `"Default"`, `"Subtle"`, `"Emphasis"`, `"Good"`, `"Warning"`, `"Attention"`, `"Accent"` |
  | `bleed` | Boolean | `false` | Whether to extend to the edges of the parent container |
  | `spacing` | String / Number | `"None"` | Spacing between the container and the element above it |
  | `gap` | Number / String | `null` | Vertical gap between child elements inside the container (e.g. `6`, `"8dp"`) |
  | `padding` | Number / Array / Object | `null` | Container inner padding |
  | `margin` | Number / Array / Object | `null` | Container outer margin |
  | `cornerRadius` | Number / String | `null` | Custom corner radius for the background and border (e.g. `8`, `"8dp"`) |
  | `minHeight` / `maxHeight` | Number / String | `null` | Container height constraints |
  | `minWidth` / `maxWidth` | Number / String | `null` | Container width constraints |
  | `items` | Array<Element\> | `[]` | Child element tree inside the container |

#### `Row` (single-row horizontal arrangement)
Used to arrange several small elements (such as a label + status dot + text) compactly on one line; commonly used in the `compact` collapsed state.

- **Properties**:
  | Property | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Always `"Row"` | - |
  | `spacing` | String / Number | `"Small"` | Spacing enum or value between child elements in the row |
  | `gap` | Number / String | `null` | Exact spacing between child elements (e.g. `4`, `"6dp"`) |
  | `padding` / `margin` | Number / Array / Object | `null` | Inner/outer margin |
  | `verticalAlignment` | String | `"Center"` | Vertical alignment: `"Top"`, `"Center"`, `"Bottom"` |
  | `items` | Array<Element\> | `[]` | List of child elements arranged horizontally |

> **Row child element weight**: each child element in a Row can additionally pass a numeric `"weight"` property to control its flexible width ratio. For example, `{ "type": "TextBlock", "text": "...", "weight": 2 }` makes that text block take 2 shares of the width. A Column / ColumnSet without a specified `weight` defaults to `weight=1`; other types don't stretch by default.

#### `Spacer` (blank placeholder)
Explicitly inserts blank spacing, for precisely controlling the gaps between elements in a Row / Column / Container.

- **Properties**:
  | Property | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Always `"Spacer"` | - |
  | `height` | Number / String | `null` | Fixed height (dp); takes effect in Column / Container |
  | `width` | Number / String | `null` | Fixed width (dp); takes effect in Row |

> When both are omitted, it occupies `Small` height by default. For flexible spacing within a Row, use the `weight` property of Row child elements.

#### `FlowRow` (auto-wrapping flow layout)
Child elements are arranged horizontally and wrap automatically; suited to scenes with an unfixed count, such as groups of Badges and tag lists.

- **Properties**:
  | Property | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Always `"FlowRow"` | - |
  | `items` | Array<Element\> | `[]` | List of child elements |
  | `gap` | Number / String | `null` | Horizontal spacing (dp) |
  | `verticalGap` | Number / String | `null` | Vertical spacing after wrapping (dp) |
  | `padding` / `margin` | Number / Array / Object | `null` | Inner/outer margin |
  | `minHeight` / `maxHeight` | Number / String | `null` | Height constraints |

#### `ScrollRow` (horizontal scrolling container)
Child elements are arranged horizontally and can be swiped to scroll; suited to content wider than the screen.

- **Properties**:
  | Property | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Always `"ScrollRow"` | - |
  | `items` | Array<Element\> | `[]` | List of child elements |
  | `gap` | Number / String | `null` | Spacing between child elements (dp) |
  | `padding` / `margin` | Number / Array / Object | `null` | Inner/outer margin |
  | `minHeight` / `maxHeight` | Number / String | `null` | Height constraints |

#### `TabSet` (tab container)
Shows multiple groups of content switched by tabs within a limited space; suited to paging information such as quota, tokens, and fees.

- **Properties**:
  | Property | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Always `"TabSet"` | - |
  | `tabs` | Array<Tab\> | `[]` | Array of tabs |
  | `tabPosition` | String | `"top"` | Position of the tab bar: `"top"` (above) / `"bottom"` (below) |
  | `tabStyle` | String | `"primary"` | Tab bar style: `"primary"` (Material indicator bar) / `"pills"` (capsule buttons) |
  | `indicatorColor` | String | `null` | Accent color of the selected state (semantic color or Hex); affects the indicator bar / capsule / selected text |
  | `tabBackgroundColor` | String | `null` | Tab bar background color (semantic color or Hex) |
  | `tabContentColor` | String | `null` | Text color of unselected tabs (semantic color or Hex) |
  | `cornerRadius` | Number / String | `null` | Corner radius of the capsules in `pills` style (dp) |
  | `padding` / `margin` | Number / Array / Object | `null` | Inner/outer margin |

- **Tab child element properties**:
  | Property | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Always `"Tab"` | - |
  | `label` | String | `""` | Tab title text |
  | `icon` | String | `null` | Tab icon name (e.g. `"external-link"`, `"copy"`, `"help"`) |
  | `badge` | String | `null` | Small badge text at the top-right corner of the tab (e.g. `"3"`, `"!"`) |
  | `color` | String | `null` | Accent color when this tab is selected (semantic color or Hex; takes precedence over TabSet's `indicatorColor`) |
  | `items` | Array<Element\> | `[]` | List of child elements under this tab |

> **Collapsed-state behavior**: in the compact state, TabSet doesn't render the tab bar; it only shows the content of the first Tab.

### 5.2 Core display elements

#### `TextBlock` (text block)
The most basic and most commonly used text layout element.

- **Properties**:
  | Property | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Always `"TextBlock"` | - |

### 5.3 Interactive button elements (ActionButton)

Buttons can be placed as ordinary elements anywhere in `body` (Row / Column / Container / FlowRow, etc.), replacing the old root-level `actions` field.

#### `ActionButton` (clickable button)
Clicking opens an external link or copies text to the clipboard.

- **Properties**:
  | Property | Type | Required | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Yes | - | Always `"ActionButton"` (aliases `"button"`, `"action"`) |
  | `title` | String | Yes | - | Button text (e.g. `"Top up"`, `"Copy key"`) |
  | `action` | String | No | `"openUrl"` | Behavior type: `"openUrl"` (open a link) / `"copy"` (copy text) / `"refresh"` (refresh the dashboard) |
  | `url` | String | Conditional | - | Required when `action=openUrl`; a complete HTTP/HTTPS link |
  | `value` | String | Conditional | - | Required when `action=copy`; the text content to copy |
  | `icon` | String | No | `null` | Name of the icon in front of the button (e.g. `"external-link"`, `"copy"`) |
  | `style` | String | No | `"Default"` | Button background style: `"Default"` (solid light tint), `"Subtle"`, `"Good"`, `"Warning"`, `"Attention"`, `"Accent"` |
  | `color` | String | No | `"Accent"` | Button text/icon color (semantic color or Hex) |
  | `padding` / `margin` | Number / Array / Object | No | `null` | Inner/outer margin |

      "url": "https://api.openai.com",
      "icon": "external-link",
      "style": "Accent",
      "color": "Accent"
    }
  ]
}

## 8. Design advice for AI assistants writing dashboard scripts

1. **Use the injected environment variables**:
   Read the real token data of each single request via `os.environ.get("AICODE_LAST_INPUT_TOKENS", "0")` and the like, and seamlessly assemble the token consumption, cache hit rate, or cost estimate for that request.
2. **Layer the information**:
   - Keep `compact` to a single refined line (e.g. `[🟢 Normal] 5h: 80% | $18.42`);
   - Have `body` provide multi-column expansion, bill details, and action buttons.
3. **Error fallback**:
   When the network times out or the API errors, output a card with `StatusDot(color="Attention")` to friendly indicate the problem.

## 5. Complete Component and Container Specification (Elements Reference)

### 5.1 Container and Layout Components

> **Common attribute `visible`**: every component can pass `"visible": false` to hide that element; it's skipped at parse time and not rendered. Suitable for dynamically controlling visibility based on environment variables.

#### `ColumnSet` (multi-column grid container)
Arranges child elements side by side in multiple horizontal columns; it's the core container for building multi-period metrics and left-right comparison cards.

- **Attribute reference**:
  | Attribute | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Fixed `"ColumnSet"` | - |
  | `columns` | Array<Column\> | `[]` | List of contained column objects |
  | `spacing` | String / Number | `"Medium"` | Column spacing enum or number (such as `8`, `"10dp"`) |
  | `gap` | Number / String | `null` | Precise spacing between columns (such as `8`, `"12dp"`, takes precedence over `spacing`) |
  | `padding` | Number / Array / Object | `null` | Container padding (such as `8`, `[4, 8]`, or `{ "top": 4, "right": 8 }`) |
  | `margin` | Number / Array / Object | `null` | Container margin |
  | `minHeight` | Number / String | `null` | Minimum height constraint (such as `48`, `"48dp"`) |
  | `horizontalAlignment` | String | `"Left"` | Horizontal alignment: `"Left"`, `"Center"`, `"Right"` |

#### `Column` (single column)
A child element of `ColumnSet`, stacking content components vertically inside.

- **Attribute reference**:
  | Attribute | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Fixed `"Column"` | - |
  | `width` | String / Number | `"stretch"` | Width mode:<br>• `"auto"`: adaptive minimum width based on content<br>• `"stretch"`: evenly divides the remaining available space<br>• Numbers like `"1"`, `"2"`, `"3"`: flexible weight ratios<br>• `"50px"`, `"50dp"`: fixed width |
  | `separator` | Boolean | `false` | When `true`, shows a thin vertical divider line from the previous column |
  | `spacing` | String | `"None"` | Vertical spacing enum for child elements in the column: `"None"`, `"Small"`, `"Medium"`, `"Large"` |
  | `gap` | Number / String | `null` | Precise vertical spacing of child elements in the column (such as `4`, `"6dp"`, takes precedence over `spacing`) |
  | `padding` | Number / Array / Object | `null` | Column padding (such as `4`, `[2, 4]`) |
  | `minHeight` / `maxHeight` | Number / String | `null` | Minimum/maximum height constraints |
  | `minWidth` / `maxWidth` | Number / String | `null` | Minimum/maximum width constraints |
  | `verticalContentAlignment` | String | `"Top"` | Vertical alignment within the column: `"Top"`, `"Center"`, `"Bottom"` |
  | `items` | Array<Element\> | `[]` | List of components arranged vertically in the column |

#### `Container` (generic block container)
Used to package several elements into an independent card, highlighted block, or grouping background.

- **Attribute reference**:
  | Attribute | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Fixed `"Container"` | - |
  | `style` | String | `"Default"` | Container style: `"Default"`, `"Subtle"`, `"Emphasis"`, `"Good"`, `"Warning"`, `"Attention"`, `"Accent"` |
  | `bleed` | Boolean | `false` | Whether to extend to the parent container's edge |
  | `spacing` | String / Number | `"None"` | Spacing between the container and the element above |
  | `gap` | Number / String | `null` | Vertical interval between child elements inside the container (such as `6`, `"8dp"`) |
  | `padding` | Number / Array / Object | `null` | Container padding |
  | `margin` | Number / Array / Object | `null` | Container margin |
  | `cornerRadius` | Number / String | `null` | Custom background and border corner radius (such as `8`, `"8dp"`) |
  | `minHeight` / `maxHeight` | Number / String | `null` | Container height constraints |
  | `minWidth` / `maxWidth` | Number / String | `null` | Container width constraints |
  | `items` | Array<Element\> | `[]` | Child component tree inside the container |

#### `Row` (single-row horizontal arrangement)
Used to compactly arrange multiple small elements (such as a label + status dot + text) horizontally on the same row; commonly used in the `compact` collapsed state.

- **Attribute reference**:
  | Attribute | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Fixed `"Row"` | - |
  | `spacing` | String / Number | `"Small"` | Spacing enum or value for child elements in the row |
  | `gap` | Number / String | `null` | Precise spacing between child elements (such as `4`, `"6dp"`) |
  | `padding` / `margin` | Number / Array / Object | `null` | Padding/margin |
  | `verticalAlignment` | String | `"Center"` | Vertical alignment: `"Top"`, `"Center"`, `"Bottom"` |
  | `items` | Array<Element\> | `[]` | List of horizontally arranged child elements |

> **Row child element weight**: each child element in a Row can additionally pass a `"weight"` numeric attribute to control its flexible width ratio. For example `{ "type": "TextBlock", "text": "...", "weight": 2 }` makes that text block occupy 2 shares of width. Columns / ColumnSets without a specified `weight` default to `weight=1`; other types don't stretch by default.

#### `Spacer` (blank placeholder)
Explicitly inserts blank spacing, for precisely controlling element spacing in a Row / Column / Container.

- **Attribute reference**:
  | Attribute | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Fixed `"Spacer"` | - |
  | `height` | Number / String | `null` | Fixed height (dp), effective in a Column / Container |
  | `width` | Number / String | `null` | Fixed width (dp), effective in a Row |

> When both are omitted it occupies `Small` height by default. For flexible placeholder space in a Row, use the Row child element's `weight` attribute.

#### `FlowRow` (auto-wrapping flow layout)
Child elements are arranged horizontally and wrap automatically, suitable for scenarios with unfixed counts such as Badge groups and tag lists.

- **Attribute reference**:
  | Attribute | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Fixed `"FlowRow"` | - |
  | `items` | Array<Element\> | `[]` | Child element list |
  | `gap` | Number / String | `null` | Horizontal spacing (dp) |
  | `verticalGap` | Number / String | `null` | Vertical spacing after wrapping (dp) |
  | `padding` / `margin` | Number / Array / Object | `null` | Padding/margin |
  | `minHeight` / `maxHeight` | Number / String | `null` | Height constraints |

#### `ScrollRow` (horizontal scrolling container)
Child elements are arranged horizontally and can be swiped to scroll, suitable when content exceeds the screen width.

- **Attribute reference**:
  | Attribute | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Fixed `"ScrollRow"` | - |
  | `items` | Array<Element\> | `[]` | Child element list |
  | `gap` | Number / String | `null` | Child element spacing (dp) |
  | `padding` / `margin` | Number / Array / Object | `null` | Padding/margin |
  | `minHeight` / `maxHeight` | Number / String | `null` | Height constraints |

#### `TabSet` (tab container)
Displays multiple content groups switched by tabs in limited space, suitable for paging information such as balances, tokens, and costs.

- **Attribute reference**:
  | Attribute | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Fixed `"TabSet"` | - |
  | `tabs` | Array<Tab\> | `[]` | Tab array |
  | `tabPosition` | String | `"top"` | Tab bar position: `"top"` (above) / `"bottom"` (below) |
  | `tabStyle` | String | `"primary"` | Tab bar style: `"primary"` (Material indicator strip) / `"pills"` (capsule buttons) |
  | `indicatorColor` | String | `null` | Selected-state accent color (semantic color or Hex), affecting the indicator strip/capsule/selected text |
  | `tabBackgroundColor` | String | `null` | Tab bar background color (semantic color or Hex) |
  | `tabContentColor` | String | `null` | Text color of unselected tabs (semantic color or Hex) |
  | `cornerRadius` | Number / String | `null` | Capsule corner radius (dp) under the `pills` style |
  | `padding` / `margin` | Number / Array / Object | `null` | Padding/margin |

- **Tab child element attributes**:
  | Attribute | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Fixed `"Tab"` | - |
  | `label` | String | `""` | Tab title text |
  | `icon` | String | `null` | Tab icon name (such as `"external-link"`, `"copy"`, `"help"`) |
  | `badge` | String | `null` | Small badge text at the tab's top right (such as `"3"`, `"!"`) |
  | `color` | String | `null` | Accent color when this tab is selected (semantic color or Hex, takes precedence over TabSet's `indicatorColor`) |
  | `items` | Array<Element\> | `[]` | Child component list under this tab |

> **Collapsed-state behavior**: in the compact state, TabSet doesn't render the tab bar and only shows the first tab's content.

#### `Divider` (divider line)
A horizontal divider line, used to separate different content blocks of a card.

- **Attribute reference**:
  | Attribute | Type | Default | Description |
  | :--- | :--- | :--- | :--- |
  | `type` | String | Fixed `"Divider"` | - |
  | `spacing` | String | `"Medium"` | Margin above and below the divider: `"Small"`, `"Medium"`, `"Large"` |

### 5.3 Interactive Action Class (Actions)

### 5.3 Interactive Button Class (ActionButton)

Buttons can be placed as ordinary elements anywhere in `body` (Row / Column / Container / FlowRow, etc.), replacing the old root-level `actions` field.

#### `ActionButton` (clickable button)
Clicking opens an external link or copies text to the clipboard.

- **Attribute reference**:
  | Attribute | Type | Required | Default | Description |
  | :--- | :--- | :--- | :--- | :--- |
  | `type` | String | Yes | - | Fixed `"ActionButton"` (aliases `"button"`, `"action"`) |
  | `title` | String | Yes | - | Button text (such as `"Go top up"`, `"Copy card key"`) |
  | `action` | String | No | `"openUrl"` | Behavior type: `"openUrl"` (open link) / `"copy"` (copy text) / `"refresh"` (refresh panel) |
  | `url` | String | Conditional | - | Required when `action=openUrl`, a complete HTTP/HTTPS link |
  | `value` | String | Conditional | - | Required when `action=copy`, the text content to copy |
  | `icon` | String | No | `null` | Icon name in front of the button (such as `"external-link"`, `"copy"`) |
  | `style` | String | No | `"Default"` | Button background style: `"Default"` (solid light background), `"Subtle"`, `"Good"`, `"Warning"`, `"Attention"`, `"Accent"` |
  | `color` | String | No | `"Accent"` | Button text/icon color (semantic color or Hex) |
  | `padding` / `margin` | Number / Array / Object | No | `null` | Padding/margin |

Example:

```json
{
  "type": "Row",
  "items": [
    { "type": "TextBlock", "text": "Insufficient balance?", "weight": 1 },
    {
      "type": "ActionButton",
      "title": "Top up",
      "action": "openUrl",
      "url": "https://api.openai.com",
      "icon": "external-link",
      "style": "Accent",
      "color": "Accent"
    }
  ]
}
```

## 6. Color Specification and Theme Mapping Table

Adaptive Cards use a semantic color system, ensuring excellent contrast and visual beauty in both Light Mode and Dark Mode:

| Semantic color (Color Key) | Light theme presentation | Dark theme presentation | Applicable business scenarios |
| :--- | :--- | :--- | :--- |
| **`Good`** | Emerald green `#10B981` | Fresh bright green `#34D399` | Ample balance, plentiful quota, service normal |
| **`Warning`** | Amber orange `#F59E0B` | Bright orange-yellow `#FBBF24` | Quota below 20%, about to trigger rate limiting |
| **`Attention`** | Rose red / alarm red `#EF4444` | Light alarm red `#F87171` | Quota exhausted, shutdown for arrears, script query errors |
| **`Accent`** | Brand blue / tech purple `#3B82F6` | Light tech blue `#60A5FA` | Main metric highlighting, secondary periods, normal progress |
| **`Default`** | Dark gray-black `#1F2937` | Pure white-gray `#F3F4F6` | Main titles, core large-type amounts |
| **`Subtle`** | Muted gray `#6B7280` | Secondary light gray `#9CA3AF` | Auxiliary units, sub-descriptions, converted exchange rates |

## 8. Design Advice for AI Assistants Writing Panel Scripts

1. **Use the injected environment variables**:
   Read the real token data of each single request via `os.environ.get("AICODE_LAST_INPUT_TOKENS", "0")` and the like, seamlessly assembling the current request's token consumption, cache hit rate, or cost estimate.
2. **Information layering**:
   - `compact` stays a refined single row (such as `[🟢 Normal] 5h: 80% | $18.42`);
   - `body` provides multi-column expansion, bill details, and action buttons.
3. **Error fallback**:
   When there's a network timeout or API error, output a card with `StatusDot(color="Attention")` to friendly-prompt the error.
