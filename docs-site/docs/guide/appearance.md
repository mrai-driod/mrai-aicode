# Appearance & Language

On the "Settings" home page, tapping "Appearance Theme", "Background Image", or "Language" opens a bottom selection sheet; your choice takes effect and is saved immediately.

## Appearance Theme

The panel has three sections: light/dark mode, color scheme, and Monet color extraction. The sheet doesn't close automatically after a selection, so you can easily compare several color schemes in a row.

### Light/Dark Mode

Three choices: follow system, always dark, always light.

### Color Schemes

Four presets, each prepared for both light and dark modes:

- **Default Blue**: the app's default blue tone.
- **Coffee**: warm terracotta + a rice-white paper-like base.
- **Graphite**: neutral cool gray, with minimal color interference.
- **Forest**: low-saturation green.

The outer ring of each color swatch is that theme's page background color and the inner circle is the primary color; the preview changes with the current light/dark mode.

Git lane colors, log level colors, and the red/green of diff additions/deletions are functional indicators and don't change with the theme, avoiding the same meaning having different colors under different themes. The code editor's syntax highlighting and the terminal color scheme are also separate settings of their own.

### Monet Color Extraction

When enabled, colors are extracted from the system wallpaper, and the color scheme selected above no longer applies (the swatches turn gray). Off by default.

Requires Android 12 or above; on lower-version devices the switch is unavailable and the description says so directly. The wallpaper palette is generated by the system, and extraction results vary considerably between phone manufacturers — if you're not happy with the result, just turn it off.

## Custom Background Image

You can set a global background image:

- **Choose image**: pick an image from the system gallery as the app's global background, overlaid on all page content (watermark effect, doesn't intercept touches). The terminal page keeps a pure black background and doesn't show the background image.
- **Opacity**: the slider shows 0% to 100%, but the effective range maps to 0% to 20% (i.e. sliding to 100% equals 20% opacity), ensuring text always stays readable. Default 15%, applied in real time as you drag.
- **Remove background**: restores the default solid-color background.

The background image file is stored in the app's private directory and is **not exported with backups**, so you'll need to set it again when you change devices.

## Language

You can follow the system language, or directly specify one of the supported languages.

## Terminal Appearance

The terminal's color theme, font, font size, and cursor style are a separate set of settings — see [Terminal](/guide/terminal#appearance-settings).
